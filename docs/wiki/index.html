Scrapelio Browser

An open-source, privacy-first desktop browser built in Python with PySide6 and Qt WebEngine. Includes an integrated AI assistant, a modular plugin system, Tor support, and advanced privacy controls — all in a clean, minimal interface.

Python + PySide6
Open Source
v3.4 · Linux x64
📖

Overview

Scrapelio Browser is a desktop web browser designed for developers, researchers, and privacy-conscious users. It combines the rendering power of Qt WebEngine (Chromium) with a rich set of built-in tools: an AI chat copilot, a hierarchical bookmark manager, a password manager, a screenshot suite, Tor integration, and an extensible plugin system.

The base browser is free and open source. Optional premium plugins extend its functionality for professional use cases. All core features — including the AI assistant — work without an account.

Installation

  1. 1
    Clone the repository

    Download the source code from the official repository.

  2. 2
    Install Python dependencies 
    pip install -r requirements.txt
  3. 3
    Configure the API key (optional — for AI features)

    Create a .env file in the project root and add your Anthropic key:

    ANTHROPIC_API_KEY=sk-ant-...
  4. 4
    Run the browser 
    python3 main.py
Tip: Run python3 check_dependencies.py to verify all required packages are installed before starting.

Verify the connection to the backend

python3 verificar_conexion_backend.py

This checks reachability of the Scrapelio API server (required for account login and premium plugin licensing).

Tab Management

Scrapelio uses a custom tab bar built on QTabWidget with a + button that always appears immediately after the last tab. Tabs are movable, closable, and can be searched in real time from the toolbar.

Key capabilities

🔄
Session restore

All open tabs are saved when the browser closes and restored on the next launch (requires login).

📑
Tab Groups

Organise related tabs into named groups with a dedicated Tab Groups panel.

🔍
Tab Search

Filter all open tabs instantly by typing in the search field in the toolbar.

↩️
Reopen closed tab

Reopen the last closed tab with Ctrl+Shift+T.

Per-tab privacy profiles

Each tab can be associated with a different browser profile, which means separate cookies, storage, and network settings. This allows you to be logged into the same site with different accounts simultaneously.

Split View: You can pin any tab as a persistent side panel visible while you browse other tabs. See the Split View section.

Bookmarks

The bookmark system offers a hierarchical folder tree stored in a local SQLite database. It replaces the flat bookmark list common in most browsers with a proper nested folder structure.

FeatureDetails
Folder treeUnlimited nesting depth. Create, rename, delete folders via right-click context menu.
Move bookmarksMove items between folders from the context menu.
Quick searchFilter bookmarks and folders by title or URL in real time.
Open bookmarkDouble-click a bookmark to open it in the current tab.
Add from toolbarClick the bookmark icon in the nav bar to save the current page. Choose the destination folder.
Favourites barA separate horizontal bar below the nav bar for quick one-click access. Toggle with the heart icon.

Automatic migration

On first launch, if a flat bookmark database from an older version is detected, Scrapelio automatically migrates it to the new hierarchical format without data loss.

History

Browsing history is stored locally in SQLite. The History panel (accessible from the nav bar or Ctrl+H) shows a time-sorted list of visited pages with search and delete capabilities.

History is linked to the user's session. When the user is not logged in, history is cleared on browser close for added privacy.

⬇️

Downloads

The Download Manager panel (Ctrl+J) shows all active and completed downloads with progress bars, file size information, and open/reveal-in-folder actions.

Downloads are handled by Qt's native download mechanism and stored in the system's default Downloads folder.

🔑

Password Manager

Scrapelio includes a built-in encrypted password manager that stores credentials locally using Fernet symmetric encryption derived from a master password via PBKDF2-HMAC-SHA256.

💾
Local encrypted vault

All credentials stored in an encrypted SQLite database. Never sent to any server.

🪟
Save banner

A non-intrusive banner appears below the nav bar when credentials are detected on a form submit.

⚙️
Password generator

Generate strong, customisable passwords with configurable length, symbols, and complexity.

🔗
Per-origin storage

Credentials are stored per URL origin (scheme + host + port) for precise auto-fill.

Note: The master password is never stored. If you forget it, the vault contents cannot be recovered. Keep it safe.
🔍

Find in Page

Press Ctrl+F to open the Find bar. It appears below the nav bar and highlights all matches on the current page. Use Enter / Shift+Enter to cycle through matches, or press Esc to close.

The find system wraps Qt WebEngine's native text search, supporting case-sensitive matching and real-time highlighting as you type.

GenTab — Generative Tabs

GenTab (inspired by Google Disco / generative tabs) allows the AI to create a fully interactive web application inside a browser tab, based on the content of your current open tabs.

Open the GenTab panel with Ctrl+G. Select which open tabs to include as context, write a prompt describing what you want (e.g. "create a comparison table of all the products in these tabs"), and the AI generates a self-contained HTML application that opens in a new tab.

Examples: Use GenTab to generate research dashboards, data comparison tables, reading lists, interactive maps, or visualisations — all from the content of your open tabs.
🧠

AI Navigation System

The AI Navigation system runs passively in the background, building a semantic index of the pages you visit using ChromaDB and sentence-transformers embeddings.

Based on your browsing session, it detects your intent (research, shopping, coding, etc.) and proactively surfaces suggestion toasts — non-intrusive notifications with actionable links related to what you are doing.

Privacy: The AI Navigation index is stored entirely on your local machine. Page content is never sent to any server for indexing.

Tor Network

Scrapelio includes native Tor support via the stem library and a SOCKS5 proxy routed through a local Tor daemon. It follows the same workflow as Tor Browser: the user activates Tor → bootstrap → automatic browser restart with all traffic routed through Tor.

How to use Tor

  1. 1
    Install the Tor daemon

    On Linux: sudo apt install tor. The daemon must be running on ports 9150 (SOCKS) and 9151 (control).

  2. 2
    Open the Tor panel

    Click the Tor icon in the left sidebar or navigate to the Tor section in Settings.

  3. 3
    Click "Connect"

    The panel shows a bootstrap progress bar. When it reaches 100%, the browser restarts with all network traffic routed through Tor.

  4. 4
    Get a new identity

    Click "New Identity" to request a fresh Tor circuit and a new exit IP address without restarting.

Warning: Tor significantly reduces browsing speed. Use it when privacy is a priority, not for streaming or downloads.

User Profiles

Profiles provide separate browser environments: cookies, local storage, cache, and privacy settings are completely isolated between profiles.

Switch profiles from the toolbar profile switcher (visible at window widths above 750 px). Each tab can optionally be pinned to a specific profile, allowing you to be logged into the same site with different accounts simultaneously.

Practical uses

  • Personal vs. work browsing in the same window
  • Testing web apps with different user accounts
  • Separating social media sessions
  • Research profiles with specific privacy settings

User Scripts

Scrapelio supports custom JavaScript injection into pages via its User Script Manager. Scripts are injected at page load time using Qt WebEngine's QWebEngineScript API.

Access the User Script Manager from the main menu. You can create, edit, enable, disable, and delete scripts. Each script targets a URL pattern and runs either at document start or document end.

Compatibility: Scrapelio user scripts follow the same conventions as Greasemonkey/Tampermonkey scripts, making it straightforward to port existing scripts.

Split View

The Split View plugin (free, built-in) adds a persistent side panel to the right of the main content area. It behaves like an independent browser tab with its own navigation bar, URL input, back/forward/reload controls, and full context menu support.

How to activate

Right-click any tab in the tab bar and choose "Open in Split View". The Split View panel appears to the right of the current tabs. You can browse normally in the main area while the Split View keeps its own page visible.

🖥️
Independent navigation

Full back/forward/reload controls and URL bar — browse independently from the main tabs.

🔗
Open in new tab

Right-click any link in the Split View to open it in a main browser tab.

💾
Persistent URL

The last URL loaded in the Split View is remembered across browser sessions.

↔️
Resizable

Drag the splitter handle to adjust how much space the Split View takes.

Plugin System

Scrapelio's plugin system is designed for extensibility. Any developer can build a plugin and distribute it freely. Plugins are loaded dynamically at runtime from the plugins/ directory, with no browser restart required after installation.

How plugins work

  1. 1
    Discovery

    The Plugin Manager scans plugins/ at startup and reads each plugin's plugin_info.json.

  2. 2
    Access check

    Free plugins load immediately. Premium plugins require a valid license or an active trial period.

  3. 3
    Load

    The manager imports plugin.py via importlib and calls initialize_plugin().

  4. 4
    Integration

    The plugin receives a reference to the browser window and can add panels, sidebar buttons, toolbar actions, and page hooks.

Built-in plugins

⬜
Split View Free Open Source

Adds a persistent side panel with a full independent browser. Keep any page visible while browsing in the main tabs. Includes navigation controls, URL bar, context menu, and session persistence.

🎨
Custom Themes Free tier

Visual theme selector and editor integrated with the browser's ThemeEngine. Supports light, dark, and fully custom themes with a real-time preview editor. Basic themes are free; the advanced editor requires a subscription.

Building your own plugin

Scrapelio's plugin API is fully documented. Any Python developer can create a plugin that adds panels, toolbar buttons, page hooks, or entirely new features to the browser.

Refer to the Plugin Development Guide for the complete API reference, code templates, and step-by-step tutorials.

Open architecture: All plugin APIs are public. Free plugins can be distributed with any license. There are no API fees or approval gates for open-source plugins.

Developer Tools

Press F12 to open the built-in DevTools panel, powered by Qt WebEngine's Chromium DevTools integration. It docks to the right or bottom of the window and provides the full Chromium DevTools experience: Elements, Console, Network, Sources, Performance, and more.

You can also open DevTools from the right-click context menu on any page by selecting "Inspect".

View Page Source

Press Ctrl+U to open the raw HTML source of the current page in a new tab.

Configuration

All persistent settings are stored in config.yaml at the project root. The file is loaded at startup by config_manager.py. You can edit it with any text editor; changes take effect on the next browser launch.

SectionKey settings
backend primary_url — the Scrapelio API server address used for authentication and plugin licensing.
frontend url, login_url, registration_url, dashboard_url — links to the Scrapelio web portal.
database Paths to the bookmark (bookmarks.db), password (passwords.db), and session (session.db) SQLite files.
logging Log level (INFO by default), log file path, max file size (10 MB), and backup count (3).
network Connection timeout (10 s), health check interval (30 s), network mode.
plugins Plugin directory, backup directory, checksum validation, cache duration (300 s).
security JWT algorithm, token expiry, secret key. Change the secret key in production.
tor SOCKS port (9150), control port (9151), enabled flag.

Environment variables

Sensitive values (API keys) should be placed in a .env file at the project root:

# .env — never commit this file to version control
ANTHROPIC_API_KEY=sk-ant-your-key-here

The .env file is loaded automatically on startup and is already listed in .gitignore.
